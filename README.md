# AssetLoop — Consumer Asset Intelligence Platform

> What if your home could tell you when to sell?

The first platform built for the 3 to 7 years of silence between purchase and resale. AssetLoop tells consumers three things no platform tells them today: **what they own, what it's worth, and when to sell** — in real time, for every item in their home.

## The website

A single self-contained HTML file with:

- 5 languages (English, Uzbek, Russian, Korean, Chinese)
- 300 question knowledge base (10 categories × 30 Q&A) in all 5 languages
- Interactive demo, savings calculator, quiz, and FAQ
- 3D phone mockup, animated particles, custom cursor
- Responsive mobile design
- Team presentation eyebrow, business model, roadmap, sources

### Run locally

Just open `index.html` in any modern browser:

```bash
open index.html
```

No build step, no server required — pure HTML/CSS/JS.

### Deploy

The site is a single static file. Deploy anywhere:

- **Netlify Drop** — drag `index.html` to https://app.netlify.com/drop
- **Vercel** — drag-drop to https://vercel.com/new
- **GitHub Pages** — push this repo, then enable Pages in repo settings
- **Cloudflare Pages** — connect this repo at pages.cloudflare.com
